## 解析概要

### 目的
T1/T2/T3 それぞれのタイムポイントについて TSS 周辺 ±5kb のメチル化密度プロファイルを計算し、保護ゾーン（TSS直上流の低密度領域）がタイムポイントによって変化するかを検定する。

### 手法
- **TSS参照**: Jeong 2016 データのPrimary TSS（2,771サイト）
- **ビン幅**: 200bp × 50ビン（±5kb）
- **密度**: sites/kb/TSS（ビン内サイト数 ÷ ウィンドウ幅(kb) ÷ TSS数）
- **保護比**: upstream_density（TSS −500〜0bp）÷ far_upstream_density（−2000〜−500bp）< 1 = 保護
- **遺伝子カテゴリ**: 制御遺伝子（Regulatory/TF, n=353 TSS） vs 非制御（n=2,418 TSS）

## 解釈

### 4mC 保護ゾーン：タイムポイント依存的な消失

| 観察 | 解釈 |
|------|------|
| 全TSS: ratio T1=0.823 → T3=0.867（1に近づく） | 4mC保護ゾーンはT3で弱まる |
| **制御遺伝子 T3: ratio=1.046 >1.0** | T3では制御遺伝子TSS直上流に4mCが**侵入**（保護が崩壊） |
| 非制御遺伝子: T1=0.821 → T3=0.845（変化小） | 非制御遺伝子の保護ゾーンはほぼ維持 |

**重要所見**: 4mCの保護ゾーンは制御遺伝子に対してT3で崩壊（ratio > 1）。これはT3（分化後期）において制御遺伝子プロモーターがR-Mメチル化に曝露されることを意味し、「発達後期の転写プログラム変更」と整合する可能性がある。

### 6mA 保護ゾーン：制御遺伝子での深化

| 観察 | 解釈 |
|------|------|
| 全TSS: ratio T1=0.867 → T3=0.921（弱体化） | 全体的に6mA保護ゾーンも弱まる |
| **制御遺伝子 T2: ratio=0.732**（全条件中最低） | T2で制御遺伝子TSS周辺の6mA枯渇が最大 |
| 制御遺伝子 T3: ratio=0.764（T2より回復） | T3では部分的に6mAが再侵入 |

**重要所見**: 6mA保護ゾーンは制御遺伝子においてT2で最も深く（ratio=0.732）、T2が転換の「ボトム」である可能性。T2では制御遺伝子プロモーター付近に6mAサイトが最も少なく、転写因子アクセスが最大化している可能性。

### ゲートキーパーモデルとの整合

- **T1**: 4mC（ratio=0.823）・6mA（ratio=0.927）両者で保護ゾーンが最も明確 → 栄養増殖期の「シールド」状態
- **T2**: 4mC密度が最大（B-1結果）かつ保護ゾーンが相対的に維持 → 転換期に両システムが機能
- **T3**: 4mCの制御遺伝子保護が崩壊（ratio=1.046） + 全体的6mA密度増加 → 分化後期の転写プログラム変更
- 制御遺伝子（Exposed TF群を含む）で特に動的変化が大きいことは、Exposed vs Shielded二分法とも整合

## 注意事項

- 本解析の「保護ゾーン」は−500〜0bpと−2000〜−500bpの密度比（簡易指標）

## 論点 C-2 への回答

> 「T1/T2/T3で TSS 保護ゾーンは変化するか」

**回答**: **4mCの保護ゾーンは制御遺伝子においてT3で崩壊**（ratio=1.046 > 1.0）。非制御遺伝子では維持（0.845）。6mAは制御遺伝子でT2に最深保護（ratio=0.732）。2つのメチル化システムが異なる時間的ダイナミクスで制御遺伝子プロモーターを「開閉」するパターンが示唆された。
