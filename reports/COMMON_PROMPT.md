# Summary Report 共通プロンプト

本ファイルは `reports/` ディレクトリ内のsummary reportを作成・更新する際の共通指針である。
主参照ドキュメント: `260204_summary_manuscript.md`

---

## 1. ファイル命名規則

```
YYMMDD_<解析内容>.md
```

- `YYMMDD`: 作成日（例: 260204）
- `<解析内容>`: スネークケース、解析が具体的に分かる名前
- 例: `260204_summary_manuscript.md`, `260204_rebase_comparative_methylome_report.md`

---

## 2. ヘッダー構造

```markdown
# [タイトル]

**作成日**: YYYY-MM-DD
**最終更新**: YYYY-MM-DD
**プロジェクト**: *Streptomyces coelicolor* A3(2) M145 [解析種別]
**対象**: [対象読者]
**解析ディレクトリ**: `[パス]`
**データソース**: [使用データベース/ツール名とバージョン]

---
```

### 最終更新の記載ルール

- ヘッダーに `**最終更新**: YYYY-MM-DD` を**必ず含める**（作成日の直下に配置）
- レポートを修正・追記した場合は最終更新日を更新する
- レポート末尾のフッターにも `*最終更新: YYYY-MM-DD*` を記載する
- 作成日と最終更新日が同日の場合でも両方記載する（後日の更新に備える）

## 4. Figure記述フォーマット（必須3要素）

全てのFigureは以下の3要素を**必ず**含むこと:

```markdown
### 【Figure】[ファイル名]

**ファイル**: `[解析ディレクトリからの相対パス]`

![alt](_fig/[プロジェクトルートからのパス])

**目的**: [1文。なぜこの図が必要か]

**方法**: [使用ソフトウェア、パラメータ、サンプル数、統計手法を簡潔に]

**結果と示唆**:
- [主要結果1]
- [主要結果2]
- **示唆**: [生物学的解釈]
```

### 規則

- **目的**: 1文で簡潔に。「〜を可視化し、〜を明らかにする」形式
- **方法**: ソフトウェア名+バージョン、主要パラメータ、サンプル数を含める。密度等の計算値は定義式も記載（例: density = sites/gene/kb）
- **結果と示唆**: 箇条書き。定量値を含める。最後に `**示唆**:` で生物学的解釈を付加
- 「主要な発見」は使用しない。全て「結果と示唆」で統一
- 画像パスは `_fig/` symlink経由（Cursor preview互換性のため）
- Figure出力は **PDF + SVG + PNG**。マニュスクリプト内ではSVGを優先参照（SVG未生成の場合はPNGにフォールバック）

### 図の読み方（オプション）

軸や色の意味が直感的でない場合、**結果と示唆**の前に追記:

```markdown
**図の読み方**:
- X軸: [説明]
- Y軸: [説明]
- 色: [説明]
```

## 5. 表のフォーマット

### データ表

```markdown
| 項目 | 値1 | 値2 | 解釈 |
|------|-----|-----|------|
| **強調項目** | **強調値** | ... | **重要な解釈** |
```

- 重要な行・値は **太字**
- 最終列に「解釈」「備考」等を付与
- padj、p値は科学表記（例: 1.3e-195）

### 統計検定結果

```markdown
| 検定手法 | 結果 | 判定 |
|---------|------|------|
| Fisher正確検定 | p = 0.001, OR = 1.32 | **有意** |
```

## 6. セクション配置順の原則

### 基本ルール: **フォーカスが同じ解析はまとめる**

セクションの配置順は、解析パイプラインの実行順ではなく、**科学的ナラティブ**と**フォーカス領域の近接性**に基づいて決定する:

1. **同一フォーカスの解析を連続配置**: 同じ対象（例: TSS距離、BGC制御、相関解析）に焦点を当てた解析セクション・Figureは、たとえ異なるパイプラインステップから生成されたものであっても隣接させる
2. **空間的解析→機能的解析→時間的解析の順**:
   - まずメチル化の空間分布（メタジーンプロファイル、TSS距離帯）
   - 次に空間分布の機能的意味（距離帯別相関、全体相関）
   - 最後に時間的ダイナミクス（Gained/Lost、MTase発現動態）
3. **統合考察の挿入**: 同一フォーカスのセクション群の末尾に、セクション間の整合性を議論する「統合考察」サブセクションを配置する
4. **検証・バリデーションは主張の直後に**: 仮説検定や帰無モデル検証は、対応する主張セクションの直後に配置する

### 現行セクション配置の例（260204_summary_manuscript.md）

```
TSS周辺メタジーンプロファイル (Fig. 2D)    ← TSS空間分布
TSS source比較 (Fig. S7)                   ← TSS空間分布
TSS距離帯別相関 (Fig. 3A)                  ← TSS距離（相関）
  └─ 統合考察: メタジーン↔距離帯相関
メチル化-発現相関（全体）(Fig. 3B)          ← 全体相関
FDR・バリデーション                         ← 相関の検証
帰無モデル検定                              ← 仮説の検証
Gained/Lostモチーフ逆転パターン (Fig. 2B)   ← 時間的ダイナミクス
MTase発現動態 (Fig. 2C)                    ← 酵素-メチル化の因果
```

## 7. 統計報告の基準

- **有意性閾値**: padj < 0.05（特記がない限り）
- DEG定義: padj < 0.05 かつ |log2FC| > 1（明記すること）
- 相関: Spearman r値、p値、FDR補正後p値を全て記載
- Fisher検定: OR（オッズ比）とp値を記載
- **FDR補正**: Benjamini-Hochberg法。補正前後の結果を区別して記載
- 信頼区間: 95% CI（二項検定、Bootstrap等）

## 12. 遺伝子ID体系

M145ゲノムには複数のID体系が併存する。**混同はデータ不整合の原因となるため注意**。

| ID体系 | 形式 | 例 | 用途 |
|--------|------|-----|------|
| **gene_id**（現行RefSeq） | SC_RS##### | SC_RS27515 | DESeq2, integrated_methyl_expression_weighted.csv, gene_master_DESeq2.tsv |
| **old_locus_tag**（旧SCO） | SCO#### | SCO5071 | 文献引用、BGC定義、KEGGアノテーション |
| **BGC_definition_manual.tsv** | SC_RS##### | SC_RS27265 | ⚠️ **旧RefSeqアノテーションのIDが残存している場合あり。gene_master_DESeq2.tsvで必ず照合すること** |

### マッピング方法

gene_masterファイルで gene_id ↔ old_locus_tag を相互変換:
```
gene_master = 05_annotation/analysis/05_annotation_260128_v1/tables/gene_master_DESeq2.tsv
```
**重要**: BGC遺伝子リスト作成時は必ず gene_master_DESeq2.tsv の gene_id を使用し、BGC_definition_manual.tsv の gene_id をそのまま使わないこと（旧アノテーションとの不整合あり、例: Act BGC SCO5071 = SC_RS27515 ≠ SC_RS27265）。

## 13. データソース記載規則

### 外部データベース

使用時は**バージョン/取得日**を明記:

| データベース | 記載例 | 用途 |
|------------|--------|------|
| REBASE | REBASE v602（2026-01-28） | R-M系認識配列 |
| NCBI RefSeq | NCBI Datasets API v2、YYYY-MM-DD取得 | ゲノム配列 |
| KEGG | KEGG REST API、sco organism code | パスウェイアノテーション |

### 保存率・密度等の計算値

計算方法が自明でない場合、**定義式と手順**を必ず記載:
- 保存率: （条件を満たす種数）/（対象全種数）× 100%、信頼区間の方法も明記
- 密度: sites/Mb = （モチーフ出現回数）/（ゲノムサイズ Mb）
- O/E比: 観測数 / GC含量ベース期待数
- 期待数の算出根拠（GC含量モデル等）を明記

### 先行研究の種名

NCBI分類名と論文記載名が異なる場合は**論文記載名を優先**し、NCBI名を注記:
- 例: *S. roseosporus* L30（Fang 2022）= NCBI上は *S. filamentosus*
